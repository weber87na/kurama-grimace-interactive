# 藏馬鬼臉互動短片

以《幽遊白書》藏馬為主題的互動網頁與直式短片專案。

## 本機執行

使用任一靜態網站伺服器啟動此資料夾，再以瀏覽器開啟 `index.html`。

片頭、片尾影片及完成的短片已一併納入 repo。完整動畫集數不納入版本控制。

## English

### Kurama Grimace Interactive

An interactive browser experience and vertical short video project featuring Kurama from *Yu Yu Hakusho*.

#### Run locally

Serve this directory with any static web server, then open `index.html` in a browser.

The intro clip, outro clip, and finished short video are included in this repository. The full anime episode is excluded from version control.
